# knowledge/ —— RAG 语料目录

`agent_brain.py` 的 `KnowledgeBase` 启动时自动加载本目录下的 `.txt`，**文件格式自由，无需重建数据库**。

## 命名与格式
| 文件名前缀 | 内容 | 每行格式 |
|---|---|---|
| `customs_rules*.txt` | 海关规则 | `标签<分隔符>规则原文` |
| `carbon_factors*.txt` | 碳排因子 | `成分名<分隔符>数值`（单位 kg CO2e/kg） |

分隔符支持 `TAB`、`==>`、`:`、`：`（按第一个分隔符切分，正文里可再含冒号）。
以 `#` 开头的行视为注释。

## 注意
- 本目录文件会**覆盖** `agent_brain.py` 内置的同名兜底条目。
- 语料正式启用前，每条规则应补 `source_ref`（法条名称 + 条款号 / 官网 URL）；
  无来源的法条与因子只能作为测试语料，不得用于对外结论。
- 当前两份 txt 是**用户指定的测试数据**，不是正式法规文本。
